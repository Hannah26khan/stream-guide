#  Stream Guide

## Overview

**Stream Guide** is an intelligent streaming recommendation web application that leverages cutting-edge AI technology to provide personalized content suggestions. The application integrates Google's Generative AI to deliver smart, real-time recommendations to users seeking guidance on what to watch or stream.

---

##  Tech Stack

### **Backend**
- **Framework:** [Flask](https://flask.palletsprojects.com/) - Lightweight Python web framework
- **AI Integration:** [Google Generative AI](https://ai.google.dev/) - Advanced AI model for content recommendations
- **Database:** [Firebase Firestore](https://firebase.google.com/docs/firestore) - Real-time NoSQL database
- **Server:** [Gunicorn](https://gunicorn.org/) - Production-grade WSGI HTTP server

### **Frontend**
- **Markup:** HTML5
- **Styling:** CSS3 with modern gradients and responsive design

### **Infrastructure & Deployment**
- **Containerization:** [Docker](https://www.docker.com/) - Container orchestration
- **Deployment Platform:** [Render](https://render.com/) - Cloud deployment service
- **Language:** Python 3.x


##  Features

-  AI-powered streaming recommendations
-  Secure Firebase authentication
-  Fast and responsive web interface
-  Cloud-deployed and scalable
